# [berrybrew — Gerenciador Perl para Windows](https://github.com/stevieb9/berrybrew)

**Tipo**: Repositório Open Source
**Autor(es)**: David Farrell (autor original) e Steve Bertrand (mantenedor atual)
**Publicado**: 2016 (atualizado continuamente)
**Acessado**: 2026-07-01

## Relevância
Equivalente do Perlbrew para ambientes Windows. Permite instalar e alternar entre
múltiplas versões do Strawberry Perl sem conflitos com o sistema. Referência para a
seção de configuração do ambiente de desenvolvimento local no stack para usuários
Windows — garantindo que o projeto seja acessível em multiplataforma desde o início.

O projeto nasceu em `dnmfarrell/berrybrew` e teve a manutenção transferida para Steve
Bertrand — **`stevieb9/berrybrew`** é o repositório oficial e ativamente mantido hoje;
o próprio README de `dnmfarrell/berrybrew` orienta a instalação a partir do repositório
de `stevieb9`. Use `stevieb9/berrybrew` como fonte de instalação e documentação.

Instalação: instalador (`berrybrewInstaller.exe`) ou clone do repositório seguido de
`bin\berrybrew.exe config` (executado como Administrador, para permitir a alteração do
`PATH` de sistema).

Documentação de uso: [berrybrew README](https://github.com/stevieb9/berrybrew/blob/master/README.md)
