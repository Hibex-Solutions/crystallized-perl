# [RabbitMQ](https://www.rabbitmq.com/)

**Tipo**: Documentação Oficial  
**Autor(es)**: Broadcom (anteriormente VMware / Pivotal)  
**Publicado**: 2007 (atualizado continuamente)  
**Acessado**: 2026-06-26

## Relevância
RabbitMQ é o message broker open source mais amplamente adotado. Implementa AMQP 0-9-1,
suporta múltiplos protocolos (MQTT, STOMP) e oferece roteamento flexível via exchanges
e filas. Foi o mecanismo de fila de mensagens do stack entre 2026-06-27 e 2026-07-07 —
substituído pelo [PgQue](pgque.md) (ver [ADR-022](../adrs/ADR-022-filas-em-postgresql.md)),
mantido aqui como referência histórica.
